# Sergio — Professional Portfolio

A responsive, single-page portfolio website built with HTML, CSS, and vanilla JavaScript.

## Preview locally
1. Extract the project folder.
2. Open `index.html` in a modern browser.

For a local development server, you can use VS Code with the Live Server extension.

## Customize before publishing
- Review every service and keep only services you are ready to deliver.
- Confirm the wording of your English C1 qualification. The current site describes it as a C1 level reported against the CEFR, not as a DALF certificate.
- Replace or expand the demonstration work samples with completed, clearly labelled portfolio projects.
- Add a professional LinkedIn URL if you want it displayed.
- Consider adding a professional photograph.
- Check the email address and all links.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `sergio-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages settings.

## Notes
- No backend or paid hosting is required.
- The Google Fonts connection requires internet access; system fonts will be used if unavailable.
- The contact buttons open the visitor's email application using a `mailto:` link.
- The dashboard figures are illustrative demo data, not real client results.
